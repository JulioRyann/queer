# PSICOQUEER

Site educativo sobre diversidade, inclusão, respeito e saúde mental.

## Publicação

O projeto foi preparado para o GitHub Pages. O arquivo principal é `index.html` e os materiais ficam em `PDF/`.

Para ativar o site no GitHub:

1. Abra **Settings > Pages** no repositório.
2. Em **Build and deployment**, selecione **Deploy from a branch**.
3. Escolha a branch `main` e a pasta `/ (root)`.
4. Salve e aguarde a publicação.

Os PDFs são rastreados com Git LFS para permitir arquivos maiores que 100 MB.
